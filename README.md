# Le Mur des cœurs — appli web

Version installable du jeu **Le Mur des cœurs**, servie par GitHub Pages : https://clementdalmay-alt.github.io/ldmc-web/

Ce dépôt ne contient que l'appli assemblée (par `outils/web.py` du dépôt source). Ne pas modifier ces fichiers à la main : ils sont remplacés à chaque version.

## Installer

- **iPhone (Safari)** : ouvrir le lien dans Safari, toucher le bouton Partager, puis « Sur l'écran d'accueil ».
- **Android (Chrome)** : ouvrir le lien, puis « Installer l'appli » (bouton sur l'accueil du jeu, ou menu ⋮ → Installer l'application).

Le jeu marche ensuite hors connexion. Quand une nouvelle version sort, un bandeau « Recharger » apparaît sur l'accueil. La progression est gardée sur l'appareil.

## Check-list sur téléphone (à chaque version importante)

1. Ouvrir le lien : l'accueil s'affiche avec les bonnes polices (titre en Playfair Display).
2. Installer l'appli : l'icône du cœur rose apparaît sur l'écran d'accueil.
3. Lancer l'appli depuis l'icône : plein écran, sans barre d'adresse.
4. Commencer l'histoire, jouer un soir, fermer l'appli, la rouvrir : « Continuer l'histoire » est proposé.
5. Mode avion : rouvrir l'appli et continuer la partie.
6. Sur iPhone : l'aide « Sur l'écran d'accueil » se ferme avec « Compris » et ne revient pas.

Polices : Inter et Playfair Display (SIL Open Font License, voir `fonts/LICENCE-*.txt`).
